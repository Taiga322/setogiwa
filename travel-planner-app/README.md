//プロジェクトの説明

1. プロジェクト概要 (Executive Summary)
「旅の設計士 AIプランナー」は、旅行の計画段階から旅行中のサポートまでをシームレスに行う、生成AI活用型のWebアプリケーションです。 ユーザーは「癒やし」「グルメ」などのテーマを選ぶだけで、Googleの最新AIモデル（Gemini 2.5 Flash）が最適な目的地と3日間の詳細な旅程を自動生成します。さらに、旅ナカ（旅行中）においては、現在の現在地や予定を把握した「AIコンシェルジュ」がチャット形式でリアルタイムにサポートを提供します。

2. 主な機能 (Key Features)
ステップバイステップのプラン生成:

直感的なテーマ選択（リラックス、アクティブ、文化探訪など）から始まり、AIがそのテーマに合った旅行先を提案。

ユーザーの曖昧な要望（例：「おしゃれなカフェに行きたい」）を汲み取り、JSON形式で構造化された3日間の具体的なスケジュールを生成します。

インタラクティブな旅程編集:

生成されたプランはタイムライン形式で表示され、ユーザーが自由に時間やスポット名を編集・保存可能。

文脈理解型 AIコンシェルジュ:

単なるチャットボットではなく、「現在作成されているプラン」と「（シミュレートされた）現在地・時刻」をAIが認識しています。

「次の予定はどこ？」「ここから近いおすすめのランチは？」といった質問に対し、旅程に基づいた的確なアドバイスを行います。

リアルタイム同期 (Firebase):

作成されたプランや編集内容はFirestoreに即座に保存され、データの永続化とリアルタイムな反映を実現しています。

3. 技術スタック (Tech Stack)
Frontend: React, Tailwind CSS

Backend / Database: Firebase (Authentication, Firestore)

AI Model: Google Gemini API (gemini-2.5-flash-preview)

工夫点: System InstructionとJSON Schemaを活用し、揺らぎのない安定した構造化データ（旅程JSON）を出力させています。

Architecture: Serverless / Single Page Application (SPA)

4. こだわり・技術的なポイント (Technical Highlights)
プロンプトエンジニアリング:

Gemini APIに対し、JSON Schemaを厳格に指定することで、パースエラーの少ない安定した旅程生成を実現しました。また、チャット機能ではシステムプロンプトに「現在のプラン内容」と「シミュレーションされたコンテキスト（天気や場所）」を動的に注入し、没入感のある対話体験を作り出しています。

堅牢なAPI通信:

fetchWithRetry ユーティリティを実装し、Exponential Backoff（指数関数的バックオフ）アルゴリズムを用いて、APIの一時的なエラーやレート制限に対して自動で再試行を行う堅牢な設計にしています。

ユーザー体験 (UX):

ローディング中のスピナー表示や、ステップごとの画面遷移、エラー時の丁寧なフィードバックなど、AIの待ち時間をストレスに感じさせないUI設計を行っています。
